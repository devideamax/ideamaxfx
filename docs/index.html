ideamaxfx

Open Source Python 3.9+ v0.1.0-dev

A Python library by IdeaMAX — designed for effects processing, color manipulation, and data transformations. Lightweight, composable, and easy to extend.

Status: Early Development This library is under active development. API may change. Documentation will expand as modules are built.

Installation

From PyPI (once published)

pip install ideamaxfx

From source

git clone https://github.com/ideamax/ideamaxfx.git
cd ideamaxfx
pip install -e .

Requirements

  • Python 3.9 or later
  • Dependencies listed in requirements.txt (auto-installed)

Quick Start

import ideamaxfx as fx

# Load, process, export
data = fx.load("input.png")
result = fx.pipeline(data, [
    fx.resize(width=800),
    fx.adjust_color(brightness=1.1),
    fx.sharpen(amount=0.5),
])
fx.save(result, "output.png")
Tip The pipeline pattern chains operations efficiently. Each step receives the output of the previous one.

Core Modules

ideamaxfx.core

Pipeline engine, data containers, and base classes. The backbone of the library.

ideamaxfx.color

Color spaces (RGB, HSL, HEX, CMYK), palette generation, color harmony, contrast analysis.

ideamaxfx.transform

Geometric transforms — resize, rotate, crop, flip, warp, perspective correction.

ideamaxfx.io

Import/export in PNG, JPEG, SVG, WebP, PDF. Batch processing support.

ideamaxfx.utils

Helper functions — validators, converters, file discovery, logging utilities.

Basic Usage

Color conversion

from ideamaxfx.color import hex_to_rgb, rgb_to_hsl

rgb = hex_to_rgb("#58a6ff")
hsl = rgb_to_hsl(*rgb)
print(f"RGB: {rgb}, HSL: {hsl}")

Batch processing

from ideamaxfx.io import batch_process
from pathlib import Path

batch_process(
    source=Path("./images"),
    output=Path("./optimized"),
    operations=[fx.resize(width=1200), fx.compress(quality=85)],
    formats=["webp", "png"],
)

Advanced Patterns

Custom pipeline step

from ideamaxfx.core import PipelineStep

class Watermark(PipelineStep):
    def __init__(self, text, opacity=0.3):
        self.text = text
        self.opacity = opacity

    def execute(self, data):
        # Your watermark logic here
        return data

# Use in pipeline
result = fx.pipeline(img, [
    Watermark("© IdeaMAX", opacity=0.2),
    fx.save_as("webp"),
])

Configuration

The library can be configured via a .env file or programmatically:

import ideamaxfx as fx

fx.config.set(
    log_level="debug",
    output_format="webp",
    quality=90,
)
